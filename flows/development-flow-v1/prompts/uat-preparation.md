# Optional UAT Preparation

Prepare only the user-selected acceptance test experience. Use the current
accepted plan and validated result to make the relevant preview/environment
available, with concise reproducible steps and expected visible outcomes.
Prefer the requested platform and any repository or user testing conventions.

Do not introduce implementation changes during preparation. If setup exposes a
defect, return the complete correction bundle to Implementation or Planning.
Do not claim UAT passed on behalf of the user. Write the assigned UAT guide only
when useful, and return the access details through the structured report. The
flow then waits for the user's recorded observation or explicit skip.
